# Predicción de Casos de Dengue en Bucaramanga con una Red Neuronal Multi-Salida

## Proyecto
Asignatura *Inteligencia Artificial Avanzada* — Ingeniería de Software, Universidad Tecnológica del Oriente.

## Descripción
Red neuronal densa que predice la cantidad semanal de casos de dengue en Bucaramanga y evalúa si esa predicción es igual de confiable para todos los grupos de la población (estrato socioeconómico, sexo y grupos poblacionales vulnerables), no solo en promedio.
